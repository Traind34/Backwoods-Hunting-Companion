BACKWOODS PLANNER CO. — V5.4

Fixes:
- Add menu is no longer clipped by the map toolbar's horizontal overflow.
- Add menu opens reliably above the Add button.
- All menu entries use the same small pinpoint graphic.
- New hunting-location placement flow inspired by modern hunting map apps:
  1. Tap Add.
  2. Choose the marker type.
  3. A fixed drop pin appears at the center of the map.
  4. Pan/zoom the map underneath the pin to position it precisely.
  5. Tap Place Pin.
  6. Name the location and save it.
- Cancel exits placement without creating a marker.
- Existing map layers, parcel selection, property saving, boundary drawing,
  access routes, GPS, and Home property summary remain intact.

The design is inspired by the general HuntWise marker workflow—select a marker
type, position it on the map, and save it—without copying HuntWise's proprietary
graphics or UI assets.
